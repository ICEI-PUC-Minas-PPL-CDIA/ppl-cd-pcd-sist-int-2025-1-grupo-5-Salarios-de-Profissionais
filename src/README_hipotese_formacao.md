# Hipótese: Formação Acadêmica vs Salários

## Objetivo
Investigar se profissionais com pós-graduação, mestrado ou doutorado tendem a receber salários mais altos que aqueles com apenas graduação.

## Resultado
✅ **HIPÓTESE CONFIRMADA** (p < 0.000001)

## Principais Achados
- **Diferença salarial**: R$ 11.682 entre graduação e pós-graduação+
- **Hierarquia**: Doutorado > Mestrado > Pós-graduação > Graduação
- **R² do modelo**: 0.611 (boa capacidade preditiva)
